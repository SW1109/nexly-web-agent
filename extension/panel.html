    模型连接
    
    
    
    
      
      
    使用 CLI 现有登录和配置，无需在插件填写 API Key。国产模型也可通过已配置兼容服务的 Claude Code / Codex 使用。
    
      
    先安装本地桥
    在项目目录执行：
    node scripts/setup.mjs
    完成后点击“刷新连接”。API 模式无需此步骤。
    
    
    
    
    
      
    支持厂商官方 API 和中转站的 OpenAI 兼容接口。配置仅存当前浏览器，不做云端同步；求解时题目仍会发送到所选服务商，请确认可信并获得页面使用许可。
    
      
    推广
    需要中转服务？nexly.guangnian.xin ↗
    可选中转服务，费用与隐私以该站规则为准；仅点击打开，不自动配置或传输题目。
    
      
    查看官方接入说明 ↗
    
      
    支持基础地址或完整 /chat/completions、/responses 地址。公网须 HTTPS；HTTP 仅限本机。
    
      
    默认仅保存在本次浏览器会话。密钥不回显、不写入日志，也不传给题目网页。
    
      
      
    
      
    
        
    12～256 个字符，不自动去除空格。请使用独立口令；无法找回。已解锁且不更换密钥时可留空。
    
        
    
        
    
      
    
      
    可直接手填完整模型 ID（豆包可填接入点 ID）；部分厂商/套餐不提供模型列表。获取列表不代表模型可调用。
    
      
    高级连接设置
    默认 180 秒，可配置 10～600 秒；获取模型最多等待 30 秒。
    首版不支持原生 Anthropic / Gemini 协议；经中转站转换为 OpenAI 兼容接口后可用。
    
      
    最终请求地址填写调用地址后显示
    
      
    
      
    连接测试只发送固定测试题，不读取当前网页；会产生少量用量。失败、超时或取消后不自动重试。
    填写并保存后即可使用。
    
    
    
  
    
  
    
    
    连续作答
    
    
    普通题自动寻找换题入口；编程题等待你提交并手动换题，再开始下一批。
