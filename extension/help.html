四个工作区，一个设置入口

  • 学习台：当前页面识别、任务摘要和连接状态。识别不自动播放或调用 AI。
  • 网课：播放与暂停、下一章、目录搜索与定位当前章节。任务始终绑定启动时的课程标签。
  • 练习：读取题目、预览答案、受控填写和样例修正；AI 数据同意在此确认，最终提交仍由人工完成。
  • 记录：集中查看练习/课程记录，可筛选；各自最新在上，清理互不影响。

设置按模型连接、课程播放、练习策略、页内组件、隐私与帮助分类。共用保存，校验失败自动定位字段，原配置无需重新填写。

操作手册

01

打开侧栏，确认数据使用说明

点击浏览器工具栏中的 QuizMate 图标并进入「练习」工作区。首次使用 AI 需明确同意将练习数据发送至你选择的服务商；未同意时不会调用 AI。仅用于允许辅助工具的学习练习。

02

选择一种模型连接

普通用户推荐 API：设置 → 模型连接 → API 模式，选择预设或填写可信中转站的地址、Key、模型；保存时按需授权该域名。可获取模型列表或测试连接，连接测试也可能产生费用。

默认 Key 只留在本次浏览器会话；勾选口令加密后需设置独立口令，重启浏览器必须解锁。更换服务商域名需要重新输入 Key。

本地 CLI：需自行安装并登录 CLI，再从项目目录执行安装命令。Chrome：node scripts/setup.mjs；Edge：node scripts/setup.mjs --browser edge --extension-id 你的扩展ID。在扩展管理页复制真实的 32 位 ID，不要输入示例文字。安装脚本支持 Windows、macOS 与 Linux 路径；具体实机验证见仓库。

03

读取练习页

选中普通 HTTP/HTTPS 练习页，点击“重新读取”。首次读取或开始答题会按需申请当前站点及跨域 iframe 的权限；允许后继续读取。也可点击“授权本站”重试。仅向可信练习页授权，不支持浏览器内部页、扩展商店、未经授权的嵌入区域。

读取时显示进度，可随时停止。读取失败时可点击错误提示下的“重新授权并读取”，此操作只读取题目。先在“查看识别内容”中核对题目、题型与编辑器；有多个可编辑区域时不会猜测目标，请关闭无关编辑器后重读。

04

预览、填写与人工确认

“仅预览答案”不会填写；“开始答题”在模型自报置信度达到 80% 后按配置写入并回读。置信度不是正确率保证，最终结果必须人工核对。

编程题可选择填写后执行页面样例。本次执行失败时，最多额外修正 2 次；修正会发送当前代码和可见执行日志。成功、达到上限或无法确认结果后，均由你人工提交代码并换题。扩展不交卷、不自动提交，也不修改网站的焦点检查、倒计时、复制限制或禁用状态。

05

暂停、连续练习与清理

页内图标悬浮或键盘聚焦后展开，可拖动；可点击“打开侧栏”查看连接与任务详情。透明度、输入节奏、连续题数都在设置中；透明度同时作用于图标和展开后的整个面板。快捷键默认 Alt + Shift + N，可在浏览器的扩展快捷键设置中调整。

任务绑定启动时的标签页。编程题提交由人工完成，人工换题后才能继续；随时可暂停、停止。停止不撤销已经填写的内容，取消请求也不保证服务商未计费。读取操作只支持停止，不能暂停。

运行中可通过“返回工作区”或 Escape 离开设置页，未保存的修改会保留，任务结束后可保存。查看旧日志时不会被新记录打断，可点击“回到最新”返回顶部。

“清除练习记录”仅清除本次浏览器会话中的题目、答案和日志。密钥可在设置中清除或锁定；卸载扩展清除扩展存储。服务商日志须向对应服务商单独申请处理。

遇到问题怎么办？
  • 连接失败：核对地址、协议、模型、余额和域名权限。API 只支持 OpenAI 兼容 Chat Completions / Responses，不支持原生 Anthropic / Gemini 接口。
  • 本地桥未连接：先点击“重新检测连接”，只检查连接，不重新求解。仍失败时打开本地桥设置，自动读取当前浏览器与扩展 ID，复制安装命令或下载修复脚本。确认 Node.js 22+、CLI 已登录；项目移动后重新安装。同一商店条目的版本更新通常保留 ID，已有桥且协议兼容时无需重新注册。本扩展不附送 CLI 订阅或 API 额度。
  • 扩展更新后页内组件失效：刷新当前练习页，再打开 QuizMate。扩展不会自动刷新页面，以便保留你的编辑。
  • 无法写入：等待编辑器加载，关闭重复编辑器，重新读取。不可编辑或按钮禁用时交给人工处理。
  • Key 忘记加密口令：无法恢复；清除后重新配置。浏览器加密不能抵御已被入侵的系统或恶意高权限软件。

网课学习 · 0.6.0 预览版

支持超星学习通、智慧树、中国大学 MOOC、国家开放大学实验学院（moodle.syxy.ouchn.cn）。仅预置这些有限站点权限，升级可能需确认；其它站点与 API 域名仍按需授权。

  1. 登录已选课程并打开视频或国开 HTML 文档、展开目录，在「网课」中识别，核对后点「开始课程」。国家开放大学裸 course/view.php 缺少课程 ID，请从平台进入实际课程。
  2. 每次开始、恢复和进入新视频时自动静音，播放中可手动取消静音。国开 HTML 文档会正常滚动至正文底部，不滚左侧目录；PDF、附件和嵌入式阅读器仍需人工阅读。视频真实结束或 HTML 文档到底并等待后，使用明确目录或唯一安全的同站“下一页”活动链接换章。播放器首次加载最多等待 15 秒，换章最多等待 22 秒，不重复点击、不使用旧播放器冒充新章节。练习、锁定、验证、登录或歧义时暂停，不伪造学时、不调用私有进度接口、不绕过焦点或验证。
  3. 随堂题可预览首题或按顺序解答并填写本页全部题目，答案在「练习」查看，不自动翻题；提交必须人工操作。自动预览默认关闭，在统一设置中主动启用，需 AI 数据同意且可能产生费用。
  4. 可暂停、停止、返回绑定课程页；后台重启或撤回权限后不自动重启。课程停止不取消已发出的 AI 请求，可到练习区单独停止。

默认 1 倍速、换章等待 3 秒、无进度 120 秒暂停，均在「设置 → 课程播放」调整。仅完成隔离模拟结构回归，不代表所有登录后课程主题兼容；遇到未知播放器请反馈脱敏页面结构。

隐私说明

更新于 2026-10-23

本说明适用于 QuizMate 浏览器扩展及可选的本地 CLI 桥。维护者通过下方项目入口接受问题和隐私请求。扩展不提供自建账号、云同步、遥测、数据出售或后台题目采集服务。

读取什么，发送到哪里

在你发起读取或已授权的练习页内，扩展识别题干、选项、填空字段、编程语言、初始/当前代码与页面地址，用于识别、填写和校验。发送给 AI 前去除页面 URL 的查询参数与片段；题干和代码内的个人信息不会自动识别，请勿输入机密。

同意数据说明并发起求解后：API 模式经 HTTPS 发给你配置的服务商，包含模型 ID、结构化题目与 Bearer Key；HTTP 仅允许本机地址。本地模式把题目交给本地 CLI，由其按账号和路由配置访问对应服务商，本扩展不读取其完整认证配置。执行纠错另发送本次代码、错误和样例输入输出。获取模型与连接测试发送 Key 和必要参数；连接测试只使用内置示例，不发送当前网页题目。

存储与保留

仅使用当前浏览器的 local / session 存储，不使用 sync。题目、答案和最多 60 条任务日志位于 session，浏览器会话结束后清除；配置与同意记录位于 local，保留到你清除或卸载。默认 Key 保存在受信任扩展上下文的 session，不暴露给题目页；可选持久保存使用 AES-GCM-256、随机 salt/IV、PBKDF2-SHA256 600,000 次派生，口令和派生密钥不持久保存，重启需解锁。CLI 自身的数据保存依其设置而定。

权限与控制

activeTab / scripting 用于当前练习页识别和用户指定的填写；storage 用于设置、密钥和会话；sidePanel 显示操作界面；webNavigation 识别 iframe 与已授权练习页导航；offscreen 让可取消的 API Worker 在关闭侧栏后继续；nativeMessaging 仅供本地 CLI 桥。可选的 HTTP/HTTPS 域名权限只在用户授权的站点/API 域名生效，没有默认授权全部网站。

你可以停止任务、清除记录、清除或锁定 Key，在扩展管理中撤回站点权限，或在设置中撤回数据使用同意。撤回同意后不能再发起 AI 求解，已发送的数据无法由扩展远程删除。卸载本地桥另运行仓库卸载命令；不会卸载 CLI 或清除其账号。

第三方与自愿支持

AI 服务商/中转站按自身隐私条款、日志留存和费用规则处理请求，可能跨境传输；扩展无法保证其不留存或代替你撤回数据。GitHub、推广站及微信仅在你主动点击或扫码时接触你的信息，各自条款适用。推广明确标注，不影响默认配置、不自动发送题目；自愿赞助不提供付费功能、正确性或通过考试的保证。

不自动提交题目、交卷、绕过平台限制或保证答案正确。请遵守网站规则、版权和考试纪律。不要在不允许 AI 辅助的考试中使用。

隐私与安全问题：私密报告安全漏洞 ↗；一般隐私请求可在 项目反馈入口 ↗ 联系维护者，请勿公开敏感内容。后续如数据处理方式有实质变化，将更新此说明并重新请求必要的同意。

课程只读识别在预置且允许访问的平台页自动触发，不自动播放/调用 AI。课程目录、题目摘要、进度快照和最多 50 条课程日志仅留在 session，偏好留在 local；“清除课程记录”可清除这些会话数据。仅主动解题或启用唯一题自动预览且同意 AI 数据使用后，发送所选题目给已配置服务，不上传课程目录、视频或文档正文，不读取账号 Cookie。
