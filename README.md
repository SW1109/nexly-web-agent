# QuizMate · 智答伴侣

[English](README_EN.md) | [中文](README.md)

> Chrome / Edge 网页练习与做题辅助扩展，支持 **API 直连** 与 **本地 CLI** 双模式。

[操作手册](docs/USER_GUIDE.md) · [隐私政策](docs/PRIVACY.md) · [权限使用目录](docs/PERMISSIONS.md) · [Edge 上架材料](docs/edge-store/SUBMISSION.md) · [反馈 Bug](https://github.com/SW1109/nexly-web-agent/issues/new?template=bug_report.yml) · [参与贡献](CONTRIBUTING.md)

QuizMate 专为允许使用辅助工具的学习与练习场景设计。扩展自动识别当前练习页面的题目、选项与代码编辑器，向你指定的大模型或本地 CLI 获取解题建议，并支持受控回读、自动填写与编程题样例验证。最终提交与交卷完全由人工操作，不自动交卷、不规避平台规则。

---

## 核心特性

- **双连接模式**
  - **API 直连模式**：免 Node.js、免本地桥，直接配置官方或 OpenAI 兼容 API（如 DeepSeek、通义千问、Kimi、GLM、豆包等），即开即用。
  - **本地 CLI 模式**：通过 Native Messaging 桥接本机已登录的 Codex、Claude Code、Gemini CLI、Qwen Code 或 Kimi CLI，沿用终端配置与本地环境。
- **全题型支持**
  - 支持单选题、多选题、判断题、填空题、简答题及编程题。
  - 深度兼容网页常见的 Monaco Editor、Ace Editor、CodeMirror 等主流代码编辑组件。
- **编程题样例自修正**
  - 编程题填入代码后可运行页面样例验证，若报错可自动将错误日志与失败代码交由 AI 分析，最多支持 2 次自动修正。
  - 代码通过或报错均留在当前题，绝不代替用户点击提交。
- **页内悬浮控制**
  - 支持直接在题目区域注入轻量悬浮控制球，悬浮展开、支持拖拽定位与快捷键微调，减少频繁切屏。
- **严格的安全与隐私**
  - API Key 默认仅保存在浏览器会话（Session Storage）中，支持可选的本地 Web Crypto（AES-GCM-256）口令加密存储。
  - 绝不收集用户数据，无任何远程遥测或外部跟踪服务。

## 快速安装与配置

### 方式一：API 直连模式（推荐，零环境依赖）

适用于不想配置本地 CLI 或 Node.js 环境的用户。

1. **获取扩展**：
   - 运行 `npm run build` 生成构建产物 `dist/extension/`（或直接使用发布的扩展压缩包并解压）。
2. **加载到浏览器**：
   - 打开 Chrome 或 Edge，访问 `chrome://extensions`（Edge 访问 `edge://extensions`）。
   - 开启右上角的 **「开发者模式」**。
   - 点击 **「加载已解压的扩展程序」**，选择项目的 `dist/extension` 目录。
3. **配置 API 服务**：
   - 点击扩展图标打开侧边栏，首次打开确认数据使用说明。
   - 点击右上角 **「设置」**，将“使用方式”切换为 **「API 模式」**。
   - 选择服务商预设（或填入自定义兼容接口地址）、填写 API Key 并选择/输入模型 ID。
   - 可点击 **「测试连接」** 验证接口可用性，完成后点击保存。

### 方式二：本地 CLI 模式（沿用本地终端环境）

适用于本地已有配置好的 Codex / Claude Code / Gemini / Qwen / Kimi 等命令行工具的用户。

**环境要求**：Node.js 22+、Chrome / Edge 浏览器。

1. **安装本地原生桥**：
   ```bash
   # Chrome 开发版：在项目根目录执行
   node scripts/setup.mjs

   # Edge：将 YOUR_EDGE_EXTENSION_ID 替换为 edge://extensions 中本扩展的真实 32 位 ID
   node scripts/setup.mjs --browser edge --extension-id YOUR_EDGE_EXTENSION_ID
   ```
   *注：Windows 在 PowerShell 中运行上述命令即可；macOS / Linux 亦可使用 `bash scripts/setup.sh`。*
   默认命令注册 Chrome 并授权开发版 ID。Edge 商店版使用商店分配的 ID，需使用 Edge 命令单独注册；从商店安装扩展不会同时安装本地 CLI 桥。已有本地环境时，可直接运行 `node scripts/install-native.mjs --browser edge --extension-id YOUR_EDGE_EXTENSION_ID` 更新注册。
2. **加载扩展程序**：
   - 开发版在 `chrome://extensions` 或 `edge://extensions` 中开启开发者模式，加载 `dist/extension` 目录；已安装商店版的用户直接使用商店版。
3. **验证连接**：
   - 在扩展侧栏的“设置”中选择 **「本地模式」**，选择对应的 CLI 工具，点击 **「刷新连接」** 显示连接正常即可。
   - 连接失败时点击 **「设置本地桥」**，自动读取浏览器与扩展 ID，复制安装命令或下载修复脚本；同一商店条目的常规更新无需更换 ID。

## 使用指南

1. **读取题目**：
   - 打开支持辅助工具的练习页面，点击侧栏 **「重新读取」**（或使用页内悬浮球）。
   - 扩展会自动识别题干、题型、选项及代码编辑器。若题目位于跨域 iframe 中，需点击一次“授权本站”。
2. **预览或作答**：
   - **仅预览答案**：仅调用模型展示解析与推荐答案，不改动网页内容。
   - **开始答题**：模型返回且置信度满足要求后，自动将答案填入对应选项或输入框，并回读核对。
3. **连续答题**：
   - 支持设置批量练习题数（1～20 题）。选择题、填空题在填写成功后会自动寻找“下一题”入口流转；编程题则始终等待人工提交和换题。
4. **快捷键与操作**：
   - 默认快捷键：`Alt + Shift + N`（开始 / 暂停 / 继续）。
   - 悬浮球：鼠标悬浮展开，离开自动收起；支持鼠标拖动或按住 `Alt + 方向键` 精细微调位置。

## 操作节奏配置

在侧边栏右上角「设置」中可针对不同平台调节防封与答题节奏：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 答案返回后等待 | 1500 ms | 模型得到答案后延迟填写的等待时间 |
| 自动操作间隔 | 800 ms | 连续点击或多项操作之间的停顿时间 |
| 字符输入间隔 | 40 ms | 模拟逐字输入的打字间隔（填空与编程题） |
| 逐字输入开关 | 开启 | 关闭后采用整段一次性填入 |

## 本地开发与调试

项目采用原生 JavaScript 开发，无第三方运行时 npm 依赖。

```bash
# 代码与清单完整性检查
npm run check

# 运行全量单元测试
npm test

# 构建打包扩展至 dist/
npm run build

# 诊断本地 CLI 与系统桥状态
npm run doctor
```

- `extension/`：Manifest V3 浏览器扩展核心源码。
- `bridge/`：本地 Native Messaging 桥接通信脚本与适配器。
- `scripts/`：项目构建、环境配置与系统注册工具。
- `tests/`：覆盖 API 协议、CLI 契约、页面解析与运行时的全量回归测试套件。

## 边界与声明

1. **人工提交准则**：本工具仅提供解题与填入辅助，**绝不自动点击「提交」、「交卷」或「结束考试」**。所有最终提交必须由用户自行核对并执行。
2. **规则遵从**：请在明确获准使用 AI 辅助的教学、练习和自测环境中使用。禁止用于正规考试或违规作弊。
3. **模型置信度**：AI 可能会产生幻觉或错误，置信度仅代表模型内部评估，不代表判题必然通过。
4. **数据隐私**：所有配置均存储在用户本机，API 凭证仅用于向用户指定的服务商发起直接请求，不经过任何中间中转服务器。
