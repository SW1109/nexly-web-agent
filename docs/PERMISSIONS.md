# QuizMate · 扩展权限使用目录与合规说明

适用版本：0.5.0
更新日期：2026-10-19

QuizMate 严格遵循浏览器扩展的 **最小权限原则（Principle of Least Privilege）** 与 **数据知情同意机制**。除扩展运行必需的界面展现与本地隔离存储权限外，0.5.0 为网课识别预置四个平台的有限域名权限；其它普通练习站点与 API 服务域名按需申请。不申请全网必选权限。升级可能出现新增权限提示，课程操作仍遵循用户启动、可暂停和不自动提交的边界。

本文档详细公开 QuizMate 在 `manifest.json` 中声明的全部权限、使用场景、技术实现及隐私安全评估。

---

## 权限清单总览

| 权限声明 | 权限类型 | 核心业务用途 | 数据敏感度 | 撤销与控制机制 |
|---|---|---|---|---|
| `activeTab` | 核心必选 | 用户主动点击操作时临时获取当前标签页上下文，读取题干信息与回填答案 | 低（受用户点击限制） | 有效期由浏览器控制；跨站导航/关闭后需重新授权 |
| `scripting` | 核心必选 | 在经用户授权的练习页中注入题目 DOM 解析脚本与悬浮辅助控制球 | 中（限受控代码注入） | 仅在用户授权的目标网页执行，设置中可关闭页内组件 |
| `storage` | 核心必选 | 保存用户本地偏好设置（`local`）、会话临时状态（`session`）及加密密钥 | 中（含可选加密凭据） | 可在扩展设置中一键清除记录、锁定或删除 API Key |
| `sidePanel` | 核心必选 | 在 Chrome / Edge 侧边栏常驻展示扩展主操作面板与日志监控流 | 低（纯 UI 展示界面） | 用户可随时收起或关闭侧边栏 |
| `nativeMessaging` | 模式专属 | 仅在「本地 CLI 模式」下与本机命令行工具（Codex/Claude/Gemini/Qwen/Kimi）安全通信 | 中（限本机构建桥） | 采用 API 模式时完全不触发，可随时运行脚本卸载本地桥 |
| `webNavigation` | 核心辅助 | 监听已授权练习页内 iframe 的题目切换与导航，保持题目状态即时刷新 | 低（仅过滤指定 Frame） | 仅处理已授权域名的导航事件，不记录历史浏览记录 |
| `offscreen` | 架构支持 | 挂载后台轻量沙箱文档（Offscreen Document），保证流式 API 请求平稳运行 | 低（无 DOM/网页访问） | 仅用于 API 请求生命周期，无网络任务时自动释放或静默休眠 |
| `host_permissions` | 有限必选站点 | 支持平台的只读课程识别、用户启动后的正常播放/换章及随堂练习 | 中（页面可见内容） | 可在扩展管理中限制站点访问，撤回后暂停课程 |
| `optional_host_permissions`<br>(`http://*/*`, `https://*/*`) | 用户自选按需 | 用户主动授权特定练习网站（读取题目/iframe）或自定义 API 接口域名 | 高（按站点隔离） | 绝不默认申请全网权限；可在浏览器扩展管理中随时移除单站授权 |

## 逐项权限深度披露

### 1. `activeTab`
- **声明目的**：当用户在练习页面中点击扩展图标、快捷键（`Alt + Shift + N`）或侧栏操作按钮时，授予扩展在当前标签页执行操作的临时凭证。
- **技术调用**：
  - 调用 `chrome.tabs.sendMessage` 与题目页面建立通信通道。
  - 获取当前页面的标题与基本 URL 信息（对外部模型请求剥离 `?` 查询参数和 `#` 片段以保护隐私）。
- **隐私边界**：
  - 由明确的用户交互授予临时访问，不能据此持续访问其它网站；
  - activeTab 不代表全网权限；课程预置站点及用户已授权站点可在已绑定后台标签继续操作，其它站点不能据此被读取。

### 2. `scripting`
- **声明目的**：在用户授权的练习网页上下文中注入受控的页面内容脚本，用于识别题型结构、回填选项或代码。
- **技术调用**：
  - 关联文件：`extension/lib/page.js`（题目提取与回填逻辑）、`extension/lib/page-controls.js`（页内悬浮控制球）。
  - 通过 `chrome.scripting.executeScript` 精准注入到练习题目所在的具体 Frame（支持跨域 iframe 练习容器）。
- **安全保障**：
  - 注入代码为扩展包内固化的纯前端 JavaScript，不执行任何远程动态代码（`eval` 或远程下载脚本已在 CSP 中彻底禁止）；
  - 绝不篡改页面本身的认证状态、不监听用户全局键盘记录（Keylogger）、不规避网页切屏或防作弊检测逻辑。

### 3. `storage`
- **声明目的**：保存扩展运行所必需的偏好参数、会话缓存以及经过安全保护的模型调用凭据。
- **分类存储机制**：
  - **`chrome.storage.local`**：长期保存用户本地非敏感配置（连接模式、界面主题、操作延时节奏、页内球坐标比例等）。
  - **`chrome.storage.session`**：临时持有当前会话状态（最近 60 条练习日志、最近 50 条课程日志与课程目录/播放进度快照、当前题目快照、解题结果与默认会话级 API Key），浏览器关闭即物理销毁。
  - **可选加密密文（`AES-GCM-256`）**：仅在用户主动启用“口令加密持久化”时，使用 PBKDF2-SHA256（600,000 次迭代）派生密钥，对 API Key 加密后存储在 `local` 中。明文口令与派生密钥绝不落盘。
- **数据流向**：全部数据存储在用户本地设备，不上传至任何自建或第三方的同步服务器。

### 4. `sidePanel`
- **声明目的**：调用 Chromium 原生的 Side Panel API，为用户提供沉浸式但无需频繁切屏的操作侧栏面板（`extension/panel.html`）。
- **技术调用**：
  - 注册 `default_path: "panel.html"`；
  - 支持用户在不遮挡当前主内容视图的前提下，实时查看大模型解析思路、调整模型参数与监控做题进度。
- **安全保障**：不具备跨标签穿透权限，不收集页面视口外的任何数据。

### 5. `nativeMessaging`
- **声明目的**：仅在用户选择「本地 CLI 模式」时使用，通过 Chromium 标准的标准输入/输出（stdio）管道与本机安装的 Native Host（`bridge/native-host.mjs`）通信。
- **技术调用**：
  - 调用 `chrome.runtime.connectNative("com.nexly.web_agent")`；
  - 允许调用本机已认证的 CLI 客户端（如 Codex、Claude Code、Gemini CLI、Qwen Code、Kimi CLI）。
- **安全保障**：
  - 仅限于通信握手（`health`）、求解建议（`solve`）与中止任务（`cancel`）；
  - 严格禁止从浏览器侧向本地桥传递任意 Shell 指令或不可信的可执行文件路径；
  - 若用户仅使用「API 直连模式」，该管道处于完全未激活状态。

### 6. `webNavigation`
- **声明目的**：很多现代做题平台将题面渲染在嵌套的 `<iframe>` 中，并在切换题目时局部重载子框架。扩展需要精准感知这些导航事件以维持状态同步。
- **技术调用**：
  - 监听 `chrome.webNavigation.onHistoryStateUpdated` 与 `onCompleted` 事件；
  - 过滤比对目标 Frame ID，当识别到已绑定的练习容器换题或重新加载时，自动触发侧栏题干更新。
- **安全边界**：
  - 仅对预置且允许访问的课程域名、或用户另行授权的练习域名生效；
  - 扩展不读取全局网络流量，不收集用户完整的历史浏览轨迹（Browsing History）。

### 7. `offscreen`
- **声明目的**：由于 Manifest V3 中 Service Worker 存在随时间休眠的特性，且侧边栏面板可能被用户临时折叠，扩展采用 Chromium 推荐的 Offscreen Document 方案承载后台 API 请求 Worker（`extension/api-runner.html`）。
- **技术调用**：
  - 调用 `chrome.offscreen.createDocument` 启动低资源开销的离屏环境；
  - 在离屏线程中发起受控的 `fetch` 请求与 SSE 流式解析；
  - 当任务完成或用户点击“停止”时，立即中止远端连接并释放内存。
- **安全边界**：离屏文档被严格配置为无 DOM 显示接口，且与外部练习页完全隔离。

### 8. `optional_host_permissions` 与站点按需授权
- **声明格式**：`["http://*/*", "https://*/*"]`（作为可选授权池，声明于 `optional_host_permissions`）。
- **核心原则——拒绝“安装即全部授权”**：
  - 0.5.0 初次安装或升级仅预置下文四项有限课程站点权限，**其它网站不默认授权**；
  - 用户在练习页点击侧边栏的「授权本站」时，浏览器将弹出原生的安全授权确认框，仅授予当前练习网站的域名权限；
  - 当用户在 API 设置中输入自定义服务商端点（如 `https://api.deepseek.com`）并点击保存时，扩展仅申请该特定服务商域名的通信权限。
- **撤销机制**：
  - 用户可随时在浏览器扩展设置页面的「站点访问权限」中，针对任意域名单独移除或改为“点击时授权”。

## Web 可访问资源说明（Web Accessible Resources）

- **声明内容**：
  ```json
  "web_accessible_resources": [
    {
      "resources": ["icons/icon-32.png"],
      "matches": ["http://*/*", "https://*/*"]
    }
  ]
  ```
- **使用目的**：仅用于在已授权的练习网页内渲染轻量级悬浮球图标（`icons/icon-32.png`），方便用户在不打开侧边栏的情况下随时识别辅助工具的运行状态。
- **安全边界**：仅暴露静态 PNG 图标，不包含任何脚本文件或内部配置数据，不会带来跨站脚本（XSS）或特权逃逸风险。

## 审查与合规自我声明

1. **无隐私逃逸机制**：扩展不使用且未声明 `cookies`、`webRequest`、`debugger`、`history`、`management` 等高危权限。
2. **纯粹本地与透明**：所有数据通信透明可查，用户可随时打开浏览器的 DevTools 网络面板与扩展控制台核查所有进出站通信。
3. **符合商店开发者政策**：完全契合 Microsoft Edge Add-ons 与 Chrome Web Store 关于单一用途（Single Purpose）、用户数据保护与清晰披露的核心政策。


## 0.5.0 预置课程站点权限

`host_permissions` 严格限定为以下四项（不包含 Cookie、debugger 或全网必选权限）：

- `https://*.chaoxing.com/*`：超星学习通课程与其同平台 iframe。
- `https://*.zhihuishu.com/*`：智慧树 / 知到课程。
- `https://www.icourse163.org/*`：中国大学 MOOC 指定主站。
- `https://moodle.syxy.ouchn.cn/*`：用户指定的国家开放大学实验学院 Moodle；不包含其它分校或整个 `ouchn.cn`。

活动平台页加载/切入时可只读识别可见目录、题目摘要与视频状态；不会因识别自动播放或调用模型。只有用户启动后才播放/尝试明确目录换章；唯一题自动预览默认关闭，启用后仍需 AI 数据使用同意。无权限、登录、验证码、未知播放器或目录歧义时暂停，不改验证、焦点或私有学习记录。不调用平台进度 API。跨域第三方播放器不在预置权限和本版适配范围。
