## 统一入口（0.6.0）

- **学习台**：展示当前标签的页面类型、课程/练习任务摘要和 AI 配置状态。点击“识别这门课程”只识别；点击“读取当前练习”只读取，不直接播放、求解或提交。切换标签不会把运行中的任务绑定到新页面。
- **网课**：识别、开始/继续、暂停、停止、下一章与回到绑定课程页集中在课程控制卡。目录支持名称搜索与“定位当前”；未识别目录时，仅允许唯一安全的同站“下一页”活动链接。
- **练习**：当前题目、答案预览、填写与执行样例。同页存在多个独立题块时，“开始答题”会依次解答当前页全部题目，完成后停止，不查找或点击上一题、下一题；此时每批题数设置不截断本页队列。网课区也直接处理当前页全部题目，无需选题；仅预览只预览当前页首题。AI 数据同意只在此确认，视频播放无需同意或配置 AI。
- **记录**：集中查看练习与课程日志，可按类型筛选。每个列表最新在上、固定高度滚动；清除按钮仍分别管理各自记录。
- **设置**：按“模型连接 / 课程播放 / 练习策略 / 页内组件 / 隐私与帮助”分类，原有配置与默认值不迁移、不重置。所有分类共用保存，校验失败自动定位字段所在分类；保存失败不会离开设置或丢失草稿。

页内组件在已授权的课程页也会自动显示，无需先读到题目；仅显示入口，不自行启动。组件可打开或关闭当前窗口的侧栏，打开时会进入对应的课程或练习区，关闭不停止课程或答题任务。重载后不自动恢复播放与 AI 任务。

## 1. 连接与模式配置

QuizMate 支持两种独立的工作模式，可在侧边栏右上角 **「设置」** 中随时切换：

### 1.1 API 直连模式（无需 CLI 或 Node.js）
- **适用场景**：日常学习与练习，快速接入主流大模型。
- **配置步骤**：
  1. 打开侧栏右上角 **「设置 → 模型连接」**，将“使用方式”选择为 **「API 模式」**。
  2. 选择厂商预设（如 DeepSeek、通义千问、Kimi、GLM、豆包等），或选择自定义输入兼容 OpenAI 规范的完整调用地址（如 `https://api.example.com/v1`）。
  3. 输入 API Key。
  4. 手动输入模型名称（或点击“获取模型”选择）。
  5. 点击 **「测试连接」**，扩展会发送一道简单的内置算术测试题以验证连通性。
  6. 验证通过后点击 **「保存设置」**。
- **密钥安全**：
  - 默认情况下，API Key 仅在当前浏览器会话中临时保存，关闭浏览器后自动失效。
  - 若勾选“口令加密保存到本机”，会通过 Web Crypto（AES-GCM-256）将密钥密文持久化至本机，重启浏览器后输入口令即可解锁。

### 1.2 本地 CLI 模式（通过本地桥连接命令行工具）
- **适用场景**：已有配置完善的 Codex CLI、Claude Code、Gemini CLI、Qwen Code 或 Kimi CLI 环境。
- **配置步骤**：
  1. 确保本机已安装 Node.js 22+ 及对应 CLI 工具并登录成功。
  2. 在项目根目录按当前浏览器执行安装脚本：
     ```bash
     # Chrome 开发版
     node scripts/setup.mjs

     # Edge：用 edge://extensions 中本扩展的真实 32 位 ID 替换 YOUR_EDGE_EXTENSION_ID
     node scripts/setup.mjs --browser edge --extension-id YOUR_EDGE_EXTENSION_ID
     ```
     默认命令只注册 Chrome，并授权从源码 key 得到的开发版 ID。Edge 商店包移除了开发 key，实际 ID 由商店分配；不能沿用开发版 ID。安装商店扩展不会同时安装或注册本地 CLI 桥，每台使用本地模式的电脑都需要执行对应命令。
  3. 在扩展“设置 → 模型连接”中选择 **「本地模式」**，挑选你要调用的 CLI 工具。
  4. 点击 **「刷新连接」**，状态显示为已连接即可开始答题。


- **Gemini 非交互调用诊断**：插件使用每次新进程的 `--prompt` + `--output-format stream-json`，沿用当前用户配置，不覆盖模型或密钥。状态会区分“启动与配置加载”“等待模型首段输出”“接收回答”“上游重试”；默认单次最长 180 秒，停止或超时会终止该任务。终端交互会话成功不等于相同源/模型的非交互调用成功；可在终端用 `gemini -p "仅回答 OK，不调用工具" --output-format stream-json` 对照，注意不要在公开反馈中粘贴密钥、完整环境变量或原始调试日志。只刷新连接并不验证模型可用性；未收到完整最终结果不会使用部分回答。

## 2. 答题与操作流程

### 2.1 题目读取与识别
- 进入练习页面后，在侧栏「练习」工作区点击 **「重新读取」**。读取中显示进度，可点击 **「停止任务」** 取消本次读取。
- 扩展会自动检测当前页面的题干、选项类型（单选、多选、判断、填空、简答）或代码编辑器（Monaco、Ace、CodeMirror 等）。
- 首次读取或开始答题时，扩展会按需申请当前站点及已加载 iframe 的访问权限；允许后继续读取。已授权站点无需重复授权，也可点击 **「授权本站」** 手动重试。
- 读取失败可点击错误提示下的 **「重新授权并读取」**；只读取页面，不会调用模型。

### 2.2 解题操作
- **仅预览答案**：只调用大模型获取解题思路与推荐答案，并展示在侧边栏中，不对网页做任何改动。
- **开始答题**：模型返回答案且置信度达到阈值后，按照设置的节奏将答案填入输入框或选中对应选项，并执行回读确认。

### 大作业参考草稿（Moodle / 国开）
- 在大作业说明页（`/mod/assign/view.php?id=...`）点击 **「重新读取」**，会单独读取作业说明、题面和可识别的最低字数要求，不把课程导航、作业状态表或原有编辑内容当题面。
- **「生成作业参考草稿」** 只调用一次模型，展示可审阅草稿及参考字符数；不自动点击“添加作业”、填写、保存草稿、换活动或提交。作业说明不完整时停止识别，不继续显示上一道题的旧答案。
- 当前作业模式仅支持草稿预览，不代表已适配“添加作业”后的真实富文本编辑器或附件。题面禁止复制粘贴时不通过脚本赋值或模拟输入绕过，请按平台规则人工录入。生成内容仍需核对事实、材料、引用和字数，最终提交由你处理。

### 2.3 编程题与样例自修正
- 对于代码编程题，扩展在将生成的代码填入编辑器后，支持运行页面现有的样例验证入口（需在设置中开启“编程题填写后执行页面样例”）。
- **自动修正机制**：若页面返回编译错误或样例未通过，扩展会自动提取报错信息和失败代码回传给 AI 进行分析，最多支持 2 次自动修正。
- **提交确认**：无论样例通过与否，扩展**绝不代点最终代码提交或交卷按钮**，用户需人工确认后自行提交并换题。

### 2.4 连续练习模式
- 批量答题数量默认 20 题，可在设置中调整为 1～100 题。
- 客观题完成当前题目的填写与校验后，会自动寻找“下一题”或“换一题”等按钮进行翻题；遇到编程题则自动停留在当前题等待用户处理。

## 3. 页内悬浮组件与快捷键

- **悬浮球使用**：
  - 页内组件默认开启；打开已授权的练习页面时，题目区域会自动展示轻量悬浮图标。
  - 鼠标悬浮即展开控制面板，离开自动收起；支持点击“开始”、“暂停”、“停止”。
  - 点击 **「打开侧栏」** 查看连接、设置与任务详情，点击 **「关闭侧栏」** 仅收起当前窗口的浏览器侧栏，不停止课程或答题任务。旧版浏览器若未提供关闭接口，会提示使用侧栏右上角的关闭按钮或升级浏览器；扩展更新后若提示连接失效，请刷新练习页。
  - 鼠标拖拽悬浮图标或按住 `Alt + 方向键` 可自定义悬浮球位置。
  - 侧边栏设置中支持调整页内组件的透明度与默认注入偏好；同一透明度同时作用于图标和悬浮展开后的完整面板。
- **快捷键**：
  - 默认全局操作快捷键为 `Alt + Shift + N`（开始 / 暂停 / 继续）。
  - 可在浏览器 `chrome://extensions/shortcuts` 中根据习惯调整。
- **任务与设置**：运行中也可点击“返回练习”或按 `Escape` 离开设置，未保存的修改保留到任务结束后再保存。查看旧日志时保留阅读位置，点击“回到最新”返回顶部。

## 4. 常见问题排查 (FAQ)

### Q1: 本地模式提示“本地桥未连接”？
- **重新检测**：点击报错下方的“重新检测连接”，仅进行连接检查，不重新求解。连接恢复后可继续操作。
- **打开设置入口**：点击报错下方的“设置本地桥”，或在“设置 → 模型连接 → 本地模式”点击“设置 / 修复本地桥”。设置页自动读取当前浏览器和真实扩展 ID，可复制对应命令、下载修复脚本、重新检测连接。
- **已有安装的修复**：下载修复脚本后，在下载文件夹运行设置页显示的 `node quizmate-bridge-setup-当前浏览器.mjs`。脚本优先查找现有安装记录；如果原项目已移动或首次安装，请获取项目源码后运行页面上的安装命令。脚本不下载代码、不读取 CLI 凭据、不发送模型请求。
- **检查 Node.js 版本**：请确保系统安装了 Node.js 22 或更高版本。
- **重新执行注册**：按当前浏览器使用第 1.2 节中的命令，随后在设置页面点击“刷新连接”。已有本地环境的 Edge 用户也可只运行 `node scripts/install-native.mjs --browser edge --extension-id YOUR_EDGE_EXTENSION_ID`。
- **确认真实扩展 ID**：本地桥的 `allowed_origins` 必须包含浏览器扩展管理页显示的真实 ID。开发版 ID 与 Edge 商店版 ID 不同；`Access to the specified native messaging host is forbidden` 表示浏览器未获该主机授权，需核对当前浏览器的注册和允许来源，单纯重新安装 CLI 无法补上这项授权。
- **商店版本更新**：在同一个商店条目上传新版时 ID 保持不变。本地桥已正确安装、协议兼容且原项目目录仍可用时，扩展更新不需要重新注册；首次安装或换到其他商店仍需按实际 ID 安装本地桥。

### Q2: API 模式测试连接报 401 或 403 错误？
- 检查 API Key 是否填写正确、是否有可用额度。
- 确认所填写的模型名称（Model ID）在该服务商账号下是否具备调用权限。

### Q3: 为什么题目没有自动识别或提示需要授权？
- 首次安装、撤回站点权限或保持侧栏打开后切换网站时，可能需要重新授权。点击 **「重新读取」** 或 **「授权本站」**，在浏览器弹窗中允许访问即可继续读取；跨域 iframe 也会按需申请其站点权限。

### Q4: 会自动交卷或提交代码吗？
- **绝不会**。QuizMate 坚持以人为本的辅助定位，所有的最终“提交代码”、“提交试卷”操作均需要用户手动点击完成。

## 网课学习（0.6.0 预览版）

### 支持范围与首次使用

| 平台 | 自动识别范围 | 当前适配方式 |
|---|---|---|
| 超星学习通 | HTTPS `chaoxing.com` 及子域 | 可见章节目录、HTML5 视频、随堂题块 |
| 智慧树 / 知到 | HTTPS `zhihuishu.com` 及子域 | 传统视频列表及可见资源目录、HTML5 视频、随堂题块 |
| 中国大学 MOOC | `https://www.icourse163.org/` | 已展开的单元目录、HTML5 视频、随堂题块；不代开隐藏章节下拉菜单 |
| 国家开放大学实验学院 | `https://moodle.syxy.ouchn.cn/` | Moodle 可见活动/导航树、HTML5 视频、HTML 文档及 `.que` 题块；不包含其它分校域名 |

本版已预置以上有限域名的读取权限，升级时浏览器可能要求确认新增权限；请在扩展管理中允许访问对应平台。其它普通练习站点及 API 域名仍按需授权，不申请全网权限。平台登录和已选课程访问资格仍由你自行完成。国家开放大学的 `/course/view.php` 不能单独作为课程地址，需要从平台进入带实际课程 ID 的已选课程。

1. 打开已登录的课程视频页或国开 HTML 文档页，展开课程目录，切到 **「网课」** 工作区。支持平台在活动标签加载/切入时尝试只读识别，也可点击 **「识别当前课程」**。
2. 核对平台、当前章节、目录和绑定标签。首次识别不会自动播放、调用模型或更改平台记录。
3. 点击 **「开始课程」**。视频会先开启静音，再正常播放；开始、恢复和切入新视频时均生效，播放过程中可自行取消静音。若浏览器阻止播放，先在原页面手动点播放，再点击 **「确认并继续」**。任务绑定这个标签；切到其它标签不会改绑，但浏览器/平台自行暂停时不会强制恢复。
4. 视频真实结束，或支持的 HTML 文档滚到正文底部并等待后，且目录唯一明确或平台存在唯一安全的同站“下一页”活动链接时才尝试换章。国开 `/mod/page/view.php` 的唯一可见 HTML 正文按约一秒一屏的节奏滚动，不滚动左侧目录；展开面板可看到滚动百分比。PDF、附件、嵌入式阅读器和无法滚动的正文交给人工处理，不以滚动外壳冒充阅读。下一项是随堂题时停下等待；无安全入口的隐藏/缺失目录、多播放器、锁定、验证码、登录或加载异常均暂停，不猜测、连点或绕过。
5. 随堂练习出现后，无需选择题目，直接点 **「仅预览首题」** 或 **「解题并填写本页」**；单题时显示“仅预览答案 / 解题并填写”。填写会按页面顺序处理本页全部独立题块，忽略题型说明块，本页完成后停止，不查找或点击上一题、下一题。题目发送给你在「模型连接」配置的本地 CLI 或 API 模型，答案显示在 **「练习」** 工作区。默认遇题暂停，不自动请求 AI；可选择仅预览，或解题并填写。填写仍受置信度和页面回读限制；**最终提交/交卷必须你手动完成**，不会自动开始限次/限时测验。
6. 人工提交或换题后，回到网课区点击 **「确认并继续」**，重新核对页面再播放。停止课程只停止播放/换章；已启动的 AI 请求可在练习区单独停止。

### 统一设置、暂停与恢复

设置入口：右上角 **「设置」→「课程播放」**。

- **连续换章**：默认开启，仅适用于明确目录或安全“下一页”活动链接，不保证全课程自动连续播放。
- **自动静音**：每次开始、恢复和进入新视频时开启原播放器静音，不更改系统音量；播放中不会反复覆盖你手动取消静音的操作。
- **播放速度**：默认 1 倍，允许 0.5～16 倍、步长 0.25；平台规则和播放器实际支持优先。
- **换章等待**：默认 3000 ms，允许 0～30000 ms、步长 1000 ms，在视频真实结束或 HTML 文档正文到底后计时；文档布局变化或离开底部会重新等待。
- **无进度暂停**：默认 120 秒，允许 30～600 秒；超时提示检查播放器、文档滚动区域或网络，不刷私有进度接口。
- **唯一随堂题自动预览**：默认关闭。主动开启并同意 AI 数据使用后，仅在当前页只有一道题时自动预览一次；多题时仍需主动点击“仅预览首题”或“解题并填写本页”。不自动填写或提交，可能产生模型费用。

暂停/停止可随时打断播放、文档滚动和待切章操作；不会删除平台记录。**「清除课程记录」** 会清除本地课程绑定、目录、进度快照和最近 50 条课程日志，不清除设置。后台重启、撤回权限或关闭课程标签后需人工核对再继续，不会悄悄重启任务。
