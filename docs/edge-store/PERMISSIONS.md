# 隐私表与权限理由

核对日期：2026-10-16。以实际包内 Manifest 和当前 Partner Center 字段为准；以下为真实实现说明，不是勾选“零数据处理”的依据。

## 单一用途
在用户授权的网页练习场景，识别题目，向用户选择的 AI 获取建议答案，预览并可选择填写，提交仍由人工完成。

## 权限理由（可供审核填写）

| 权限 | 用途与边界 |
|---|---|
| activeTab | 用户主动操作时访问当前练习页，不默认授予所有网站 |
| scripting | 注入包内识别/填写逻辑及页内控制组件，不下载执行远程扩展脚本 |
| storage | 本机设置、受信任会话、题目/答案/最多 60 条日志；可选加密密钥，不使用 sync |
| sidePanel | 在浏览器侧栏展示题目、结果、设置与人工控制 |
| nativeMessaging | 本地模式调用独立安装的 CLI 桥；API 模式不需要安装桥 |
| webNavigation | 识别练习页 iframe 与导航变化，维持已绑定题目；不保存浏览历史 |
| offscreen | 承载可取消的 API Worker，保持用户已发起的请求不受侧栏关闭影响 |
| optional http/https host origins | 用户自定义练习站、跨域题目 iframe 和服务商 API 域名，无法预先枚举；由用户按域名授权，不预授全部网站 |

无需 cookies、debugger、clipboard、downloads、unlimitedStorage、notifications。商店包没有默认 host_permissions，也没有 externally_connectable 或后台内容脚本全站匹配。

## 数据披露

不能仅因“配置保存在本机”就选择“不访问/传输数据”。按当前控制台定义如实披露：
- 网站内容：题目、选项、代码、用户输入和可见执行日志，会发给用户选定的 AI/CLI 服务商。
- 网站地址：仅题目 origin/path 发给 AI，查询参数和片段删除；不保留完整浏览历史。
- 认证信息：用户配置的 API Key 用于向其服务商认证；默认仅本地会话，可选口令加密。不是读取用户的网站密码。
- CLI 账号和实际远程处理由用户 CLI 配置决定，第三方仍可能收费、留存或跨境处理。
- 无维护者遥测、账号注册、出售、广告画像和无关第三方上传；推广仅为用户主动打开的可选链接。
- 微信赞助仅是可选图片，扩展不处理支付。无真实收款图片时不显示。

## 远程代码说明

扩展本身不加载远程 JavaScript/WASM，不使用 eval/new Function，也不把模型回复作为扩展代码执行。API 响应作为结构化答案经过本地校验再展示/写入。

**必须向审核明确说明**：编程题的答案包含模型生成的源码，用户可选择将它填入题目网站编辑器并运行页面自己的样例入口；运行发生在第三方题目平台，不是扩展权限下执行。可选 Native Host 只调用固定白名单 CLI，不执行模型生成的 shell 命令。不得用“完全不会执行任何远程生成代码”掩盖这一功能，最终分类与审核由商店决定。

## 审核风险与义务

功能仅面向获准的练习，禁止绕过监控、网站限制或考试纪律；描述不可承诺正确率、通过考试、隐藏 AI 使用或官方合作。所有官网/模型兼容性与支付说法需据实，不宣称“所有平台均支持”。确认提供 Logo 与收款码的使用权；当前仓库没有授权许可证时不要对外宣称已有特定开源许可。
