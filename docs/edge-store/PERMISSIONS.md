# 权限与数据披露说明

## 单一用途
在用户授权的网页练习场景下识别题目，向用户所配置的 AI 服务获取建议答案，提供预览并按用户操作填入，最终提交由人工完成。

## 权限用途说明

| 权限声明 | 用途解释 |
|---|---|
| activeTab | 仅在用户主动操作时访问当前练习标签页，读取题目并完成受控填入 |
| scripting | 向当前练习页注入页面识别逻辑与页内悬浮控制组件 |
| storage | 存储用户本地偏好设置、会话临时状态及可选的加密 API Key |
| sidePanel | 提供扩展的主操作界面与侧边栏控制面板 |
| nativeMessaging | 仅在本地 CLI 模式下用于与本地桥接工具建立通信 |
| webNavigation | 感知已授权练习页内 iframe 的导航与页面切换，保持题目状态同步 |
| offscreen | 维持后台异步 Worker 的稳定执行，确保侧栏临时收起时不中断当前请求 |
| optional host permissions | 用户按需授权特定练习网站或自定义 API 域名，不默认申请全网权限 |

## 数据流转披露

- **题目内容**：当前练习页的题干、选项、代码及报错日志，经结构化提取后直接发送至用户选定的 AI 服务商。
- **页面 URL**：仅包含练习页的 origin 和路径信息，已过滤所有 URL 查询参数（Query Parameters）和哈希片段。
- **用户凭证**：用户配置的 API Key 仅保存在本地，直接用于向所配置的服务商请求认证，不向任何第三方服务转发。
- **无追踪遥测**：扩展本身不设中心化服务器，不收集用户使用统计、不包含任何第三方广告或遥测 SDK。
