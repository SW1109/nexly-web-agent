# 审核测试指引 (Reviewer Notes)

**扩展名称**：QuizMate · 智答伴侣 (Version: 0.6.2)

---

## 1. 基础功能验证（无需 API 凭证）

1. 在 Edge / Chrome 中加载扩展程序，点击工具栏图标打开侧边栏界面。
2. 首次启动时会展示“数据使用说明”，支持查看说明、操作手册或隐私政策。
3. 打开侧栏右上角 **「设置」**：
   - 支持切换“本地模式”与“API 模式”。
   - 在 API 模式下可查看服务商预设、接口地址格式提示及高级选项。

---

## 2. API 模式功能测试（使用 OpenAI 兼容服务）

1. 进入“设置” → “模型连接” → “使用方式”选择 **「API 模式」**。
2. 填入测试用的 OpenAI 兼容 API 地址（如 `https://api.example.com/v1`）、测试 API Key 及模型名称。
3. 点击 **「测试连接」**，扩展会发送一道固定简单的示例算术题（`2 + 2 = ?`）验证网络连通性与 JSON Schema 契约校验。
4. 打开任意包含练习题目的测试网页（单选、多选题或代码编辑器），进入侧栏 **「练习」** 并点击 **「重新读取」**，扩展将解析题目内容。
5. 点击 **「仅预览答案」**：AI 返回建议答案，侧边栏展示解题分析，不对网页进行修改。
6. 点击 **「开始答题」**：当模型置信度达标时，自动将答案填入网页表单，并在完成后提供回读提示。
7. 最终交卷/提交完全由人工完成，扩展不会自动提交试卷。

---

## 3. 本地 CLI 模式（可选）

本地 CLI 模式依赖本机单独安装并登录的 CLI 工具及 Native Messaging 宿主配置。若未配置本地环境，建议主要测试纯浏览器的 API 直连模式。


## 4. 网课学习预览版

1. 安装/升级会新增四项有限平台 host permissions，详细域名见 `PERMISSIONS.md`。在「学习台」查看支持平台，在「网课」正常播放、查看目录和暂停/停止；日志统一在「记录」，配置集中于「设置 → 课程播放」。
2. 需审核人员自行持有允许测试的已选课程账号。本项目不提供账号，不读取 Cookie，不保证所有定制主题。国家开放大学仅限实验学院站点，进入实际带课程 ID 的页面；裸 `/course/view.php` 会明确提示缺少课程 ID。
3. 识别本身不播放或调用 AI；点击开始后使用原 HTML5 播放器。只在真实结束且目录明确或存在唯一安全的同站“下一页”活动链接时换章；测验/锁定/登录/验证码/未知页面暂停。不会自动开始限次考试、提交、标记完成或调用私有进度接口。
4. 选择随堂一题可复用已配置模型预览/填写。自动预览默认关闭，启用有费用/数据提示；最终提交仍人工操作。
5. 开发自检可通过 `NEXLY_COURSE_BROWSER_TEST=1` 运行隔离 Chromium 模拟课程测试；真实平台登录和课程主题需要单独人工验收，模拟测试不代表平台认证或官方支持。
