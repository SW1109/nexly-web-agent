# 审核测试说明草稿

QuizMate 0.4.0，桌面 Edge Manifest V3 扩展，界面语言 zh-CN。

## 无账号可检查

1. 安装 `quizmate-edge-v0.4.0.zip`，点击工具栏图标打开侧栏。
2. 首次数据说明在未确认前禁用求解；仅同意后才可发起 AI 请求。
3. 打开操作手册、隐私说明、仓库、Bug 与建议入口；二维码素材未配置时展示未开放说明。
4. 在设置选择 API 模式，输入格式错误的地址，检查就近错误提示；模型与 Key 不回显到任务日志。
5. 无需 CLI 或原生桥即可使用 API 模式。默认本地模式若找不到桥，会给出安装指引，不视为 API 不可用。

## 完整 API 测试（发布者需提供，勿公开提交凭证）

- 需要可用的 OpenAI 兼容 HTTPS endpoint、独立审核 Key、可调用模型 ID 与额度。
- **当前材料不包含真实审核 Key 或服务商账号。发布者必须通过 Partner Center 私密测试备注等合适渠道补充，或确认审核允许自行配置。不能把“未配置”当作已通过功能验收。**
- 先用“测试连接”，仅发送内置 2+2 示例；可能消耗配额。
- 在用户有权使用且允许 AI 的普通练习页“重新读取”，必要时授权 iframe 站点。预览答案不填写；开始任务可填写，最终提交由人工操作。
- 自报置信度 ≥80% 才自动填写，不保证正确。多个编辑器或目标不明时停止。
- 编程题“执行样例”可发送本次错误/代码继续修正，最多额外两次。成功后等待人工提交和换题。不自动交卷，不修改网站焦点检测、禁用按钮或倒计时。
- 服务商可能单独记录请求/收费；取消只停止本地接收，不能保证远端不计费。

## 可选本地模式

需 Node.js 22+、已登录的 CLI 和本机项目源码。使用真实商店扩展 ID 安装：

```sh
node scripts/install-native.mjs --browser edge --extension-id 真实32位ID
```

允许来源只有该明确 ID，Chrome 和 Edge 分开注册。扩展 ZIP 不含 CLI、Node、本地桥安装程序、系统凭据或远程脚本；安装 CLI 桥不是 API 模式前置条件。

## 当前验证边界

本仓库的单元/夹具/Chromium 回归和真实服务商、真实题目平台、Windows/Edge 实机是不同验收层级。最终执行结果以本次交付说明为准；不要把测试截图或静态材料当作 Edge 认证。没有实测的系统/平台不写“全部兼容已验证”。
