# 简体中文商店信息

## 产品名称
QuizMate · 智答伴侣

## 简短描述
AI 辅助做题助手：通过本地 CLI 或 OpenAI 兼容 API 求解网页练习，核对后填写，不自动提交。

## 完整描述
QuizMate 是一款专为网页学习与练习设计的 AI 辅助做题扩展。在用户允许使用辅助工具的学习场景下，识别网页题目并获取大模型解题建议，支持答案预览、受控自动填写与回读校验。

主要功能：
• 支持单选、多选、判断、填空、简答及编程题等常见练习题型。
• API 直连模式：支持配置主流大模型及 OpenAI 兼容 API（如 DeepSeek、通义千问、Kimi、GLM、豆包等），即开即用，无需本地环境。
• 本地 CLI 模式：支持通过本地桥接调用 Codex、Claude Code、Gemini CLI、Qwen Code、Kimi CLI 等命令行工具。
• 编程题样例自修正：编程题支持运行页面现有样例，运行失败可由 AI 分析日志并自动修正（最多 2 次）。
• 页内悬浮控制球：支持页面内快捷悬浮控制，支持拖拽定位与快捷键微调。
• 安全凭证保护：API Key 默认仅保存在浏览器会话中，支持可选的本地 AES-GCM-256 口令加密存储。

特别声明：
• 本扩展不代点“最终提交试卷”或“提交代码”，交卷操作由用户手动完成。
• 请遵守目标网站的练习规则，严禁用于正式考试作弊。
• 本扩展与任何题目平台或特定大模型服务商无官方隶属关系。
