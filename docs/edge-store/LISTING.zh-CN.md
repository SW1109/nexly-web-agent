## 简短描述

## 完整描述
QuizMate 是面向学习练习的 AI 辅助工具。识别网页题目后，向你自己选择的 AI 服务获取建议答案，支持预览、按需填写和人工核对。请仅在允许使用辅助工具的场景使用。

主要功能：
• 单选、多选、判断、填空、简答及编程题的识别与建议答案。
• API 模式：自行配置可信服务商或中转站的 OpenAI 兼容接口地址、Key 与模型，无需本地 CLI。
• 本地模式：通过单独安装的 Native Messaging 桥，调用 Codex、Claude Code、Gemini、Qwen Code、Kimi CLI。需 Node.js 22+、已登录的 CLI 及与当前浏览器 ID 对应的安装配置。
• 答案预览、受控填写与回读校验；自定义输入/点击节奏，可随时暂停或停止。
• 编程题可执行页面样例并根据本次错误修正，最多额外两次；人工提交代码、人工换题，不自动交卷。
• 可拖动的页内控制组件、集中设置、最新在上的任务记录。
• 默认 Key 只留在浏览器会话；可选口令加密保存到本机，重启需解锁，不做配置云同步。

重要说明：
• 不提供模型订阅、API Key 或调用额度。第三方可能收费，连接测试及自动修正也可能产生费用。
• 求解会发送题目、代码等数据给你选择的服务商；首次使用需确认数据说明。服务商政策与费用由其决定。
• AI 可能错误；置信度是模型自报值，不是正确率保证。最终答案、代码与提交必须由你核对。
• 只支持普通 HTTP/HTTPS 练习页及已授权的 iframe；并非所有平台/编辑器均可识别。浏览器内部页与禁止访问区域不受支持。
• 不绕过切屏检测、倒计时、复制/编辑限制或网站安全机制；请勿用于禁止 AI 辅助的考试。
• 使用现有浏览器侧栏功能，当前面向桌面版 Chrome / Edge；不宣称移动端可用。
• 设置中有明确标注且完全可选的第三方中转站推广入口；帮助页可有自愿赞助，不解锁功能、不影响模型选择。
• 与 Microsoft、Google、题目平台及 AI 服务商无隶属或官方合作关系。
