# QuizMate 隐私说明

更新日期：2026-10-16。适用于 QuizMate 浏览器扩展及可选的本地 CLI 桥。维护者通过[项目反馈](https://github.com/SW1109/nexly-web-agent/issues)接受一般请求；安全漏洞请[私密报告](https://github.com/SW1109/nexly-web-agent/security/advisories/new)，不要公开敏感信息。

## 功能与处理目的

扩展识别用户授权练习页中的题目，向用户所选 AI 获取建议答案，按用户操作填写并回读；最终提交由人工完成。仅用于允许辅助工具的练习，不绕过网站规则、自动交卷或保证答案正确。

没有自建用户账号、题库、云同步、遥测或数据出售服务，不把练习数据自动上传给项目维护者。页面内容和 AI 响应均为不可信数据，不作为扩展系统指令执行。

## 读取和发送的数据

- 练习页：题干、选项、填空字段、代码、编程语言、页面地址及用于定位的编辑器状态。发送给 AI 前去除 URL 查询参数与片段，不自动识别题干/代码内的个人信息；用户应避免输入机密。
- API 求解：通过用户配置的 HTTPS 服务商发送结构化题目、模型 ID 及鉴权 Key。HTTP 仅允许本机 localhost / 127.0.0.1 / [::1]。不携带网站 Cookie，不允许请求重定向。
- 本地 CLI 求解：把结构化题目交给所选本地 CLI，由其现有账号和路由向其服务商请求。扩展不复制或展示完整 CLI 鉴权配置；CLI 及其服务商的日志由其自身设置决定。
- 执行纠错：用户开启“填写后执行页面样例”或主动执行样例后，本次执行失败时可额外发送当前代码、可见错误日志、样例输入/输出，最多自动修正两次。可能产生额外费用。
- 连接测试/模型列表：只发送 Key、模型等必要参数；连接测试使用内置算术示例，不发送当前网页题目。

首次求解前需明确同意数据使用说明。可以在设置中撤回同意；撤回阻止后续求解，不能撤回已经发给第三方的请求。用户主动的连接测试可能计费；停止/取消也不保证远端未处理。

## 本地存储与保留

| 数据 | 位置 | 保留与清除 |
|---|---|---|
| 偏好、连接地址、模型、数据使用同意 | 浏览器 `storage.local` | 用户清除或卸载扩展前保留 |
| 题目、答案、任务状态与最多 60 条日志 | `storage.session` | 会话结束清除；可在面板手动清除 |
| 默认 API Key / 解锁后的 Key | 限受信任扩展上下文的 `storage.session` | 浏览器会话结束、清除或锁定时移除 |
| 自愿启用的加密 Key | `storage.local` 密文 | 清除 Key 或卸载时删除；忘记口令无法恢复 |
| 本地桥启动路径与扩展 ID | 本机安装文件 | 卸载桥时删除其对应安装文件；不清理 CLI 自己的数据 |

不使用 `storage.sync`。口令加密为 AES-GCM-256、随机 salt/IV、PBKDF2-SHA256 600,000 次派生，并绑定服务商 origin；不持久保存口令或派生密钥，浏览器重启需解锁。旧明文凭证仅迁移为本次会话可用，成功后删除旧明文。浏览器加密不是系统安全保证，不能防御已入侵的系统、高权限恶意软件或恶意扩展更新。

## 权限

- `activeTab` / `scripting`：识别和填写用户指定的练习页；所有执行逻辑随扩展打包，不下载远程扩展脚本。
- `storage`：保存配置、会话及可选加密密钥。
- `sidePanel`：显示操作界面。
- `webNavigation`：识别 iframe、导航及已授权练习页的题目变化；不保存完整浏览历史。
- `offscreen`：运行可取消的 API Worker，关闭侧栏不打断用户已发起的任务。
- `nativeMessaging`：仅在本地模式连接用户自行安装的 CLI 桥。
- 可选 `http://*/*` / `https://*/*`：为了适配不同练习平台、iframe 与自定义 API 域名。实际只在用户按需授予的域名上生效，没有默认授权全部网站。不请求 Cookie、调试器、剪贴板、下载或原生通知权限。

可在浏览器扩展管理中撤回站点权限、移除扩展。在面板清除练习记录或在设置清除/锁定 Key。撤回同意不会替用户清除服务商记录；服务商删除请求须直接向其提出。本地桥独立卸载，不会删除 CLI、ccSwitch 账号或自定义配置。

## 第三方、推广与赞助

用户所选 AI 服务商/中转站适用其自身隐私政策、留存、收费与地域规则，可能跨境传输。扩展无法保证第三方不留存数据。

GitHub 仅在用户主动打开项目/反馈时访问；用户自行提交的截图、日志会按 GitHub 规则公开或处理。API 设置中的中转站推广明确标注、完全可选，不自动配置或发送数据。微信赞助仅展示维护者真实提供的图片，扫码后由微信处理；扩展不收集付款信息、不统计交易、不检测支付结果，不以赞助解锁功能。没有真实收款码时不显示收款入口。

隐私处理方式如有实质变化，将更新说明并重新征求必要同意。公开部署本说明的网页地址须由发布者确认可访问后填写到商店，不使用未部署的 URL 冒充已发布政策。
