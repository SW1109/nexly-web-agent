# QuizMate 隐私说明

本说明适用于 QuizMate 浏览器扩展及可选的本地 CLI 桥接程序。

---

## 1. 核心原则

- **无自建中心化服务**：QuizMate 不设任何用户账号系统、不搭建云端存储服务器、不收集任何使用遥测数据或分析日志。
- **本地存储与直连通信**：扩展的所有配置与会话状态均保存在用户当前浏览器本地；API 请求直接由浏览器发送至用户配置的模型服务商，不经由任何第三方中转镜像。

---

## 2. 数据的读取与流转

1. **练习页面数据**：
   - 当用户在练习页面主动触发“读取”或“答题”操作时，扩展会读取当前题目的题干、选项、填空文本框、代码编辑器内容及编程语言。
   - 提取的数据仅用于构建发往大模型的提示词（Prompt），并去除 URL 中的查询参数（Query String）与哈希片段（Hash Fragment）。
2. **大模型 API 交互**：
   - 在 API 模式下，题目数据与用户配置的 API Key 将直接通过 HTTPS 发往用户指定的服务商端点。
   - 在本地 CLI 模式下，题目数据通过系统本地管道传递给用户本地安装的命令行工具，由命令行工具按其自身配置与远端服务通信。
3. **编程题执行错误日志**：
   - 当用户开启“执行页面样例”且样例运行失败时，本次可见的错误输出与失败代码会回传给大模型用于自动修正。

---

## 3. 本地存储管理

| 数据类别 | 存储位置 | 生命周期与清理 |
| --- | --- | --- |
| 偏好设置、连接模式、自选模型 | `chrome.storage.local` | 长期保存在当前浏览器本地，可随时在扩展设置中修改或重置 |
| 题目快照、解题结果、运行日志 | `chrome.storage.session` | 仅保存在内存中，关闭浏览器或点击“清除记录”后立即销毁 |
| 默认 API Key | `chrome.storage.session` | 仅在当前浏览器会话中临时持有，浏览器重启后自动失效 |
| 加密 API Key（可选） | `chrome.storage.local` | 仅当用户主动勾选加密保存并设置独立口令时，以 AES-GCM-256 密文形式存储 |

---

## 4. 浏览器权限说明

QuizMate 遵循最小必要权限原则：
- `activeTab` / `scripting`：用于在用户主动触发时读取题目页面并填入答案。
- `storage`：用于保存用户的本地偏好设置与会话状态。
- `sidePanel`：用于提供侧边栏主操作界面。
- `nativeMessaging`：仅在本地 CLI 模式下用于与本地桥接脚本建立标准输入输出通信。
- `webNavigation`：用于感知题目 iframe 的导航与页面切换，确保连续答题时及时刷新状态。
- `offscreen`：用于支持后台 Worker 稳定发起可取消的 API 请求，防止侧边栏临时关闭时打断解题。
- 可选域名权限（Host Permissions）：仅在用户主动点击“授权本站”或保存自定义 API 域名时，按需授予对应站点的通信权限，绝不默认申请全网权限。

---

## 5. 免责声明

用户所调用的远端大模型服务（包括官方 API 及第三方兼容接口）适用其各自的服务条款与隐私政策。QuizMate 无法控制亦不对第三方服务商对题干数据的数据留存、训练使用或日志存储承担责任。请勿在题目中输入或提交包含个人敏感信息、商业机密或机密代码的内容。
