# QuizMate · 隐私政策与个人信息保护声明

适用版本：0.6.2
更新日期：2026-10-23
生效日期：2026-10-19

感谢你使用 **QuizMate · 智答伴侣**（以下简称为“本扩展”或“我们”）。QuizMate 是一款专为练习和辅助学习场景设计的浏览器扩展工具，支持通过用户自主配置的大语言模型（LLM）API 或本机命令行（CLI）提供做题参考。

我们高度重视用户的隐私安全与个人数据保护。本隐私政策旨在向你清晰、透明地阐明我们在你使用本扩展时如何处理你的数据、我们坚持的最小化原则，以及你如何管理自身的数据权益。

---

## 1. 核心隐私原则

1. **零自建中心化服务器**：本扩展不设立任何后端云服务器，不提供用户注册登录账号体系，不保存、不汇总、不转售任何用户个人信息或做题内容。
2. **零远程遥测与追踪**：本扩展代码中严禁包含任何 Google Analytics、友盟、Sentry 或其他第三方数据统计、分析或行为追踪 SDK。
3. **端到端直连与本地驻留**：所有题目解析请求直接从你的浏览器（或本机本地桥）发送至你指定的服务商端点；所有用户偏好和配置仅保存在你的设备本地。
4. **知情同意与主动授权**：初次使用本扩展前，必须由你明确阅读并确认数据使用说明；在未获得你的许可前，扩展绝不向外部服务商发送任何练习内容。

## 2. 我们处理的数据类型与处理方式

### 2.1 练习页面题目数据
- **数据范围**：在你主动读取/解题、启用连续练习，或主动开启网课唯一题自动预览并开始课程时，扩展会在当前激活的练习页面中提取当前题目的**题干文本、选项文本、填空占位符、编程语言类型以及代码编辑器中的初始模板/当前代码**。
- **大作业草稿**：主动读取 Moodle 大作业时，仅提取可见作业说明、题面及字数要求，用于生成参考草稿；不提取作业状态表、个人成绩或现有答题框原稿，不自动填写、保存、换活动或提交。Gemini 事件流在本地解析，浏览器进度只接收固定阶段标签，不接收原始 stderr、会话 ID 或额外本地上下文。
- **URL 脱敏处理**：在将页面来源信息附带于请求上下文前，扩展会自动剔除 URL 中的所有查询参数（Query String，如 `?token=...&userId=...`）和哈希片段（Hash Fragment），仅保留基础域名与路径，防止敏感令牌意外泄露。
- **处理目的**：用于组织发给大语言模型的解题提示词（Prompt），并根据返回结果执行比对与核对。

### 2.2 编程题运行报错日志（可选）
- **数据范围**：仅当你主动开启“填写后执行页面样例”功能，且页面运行测试用例明确报错时，扩展会读取网页上**当前可见的执行报错日志与未通过的代码片段**。
- **处理目的**：将报错信息作为上下文交给 AI 模型进行自修复尝试（最多 2 次），辅助排查代码语法或逻辑错误。修复完成后数据即销毁，不作长期保留。

### 2.3 网课页面数据（0.6.2 预览版）
- **只读识别**：在预置且浏览器允许访问的超星、智慧树、中国大学 MOOC 和国家开放大学实验学院站点，活动标签加载/切入时可只读识别可见课程标题、章节目录、题目摘要、HTML5 视频进度及支持的 HTML 文档滚动状态；识别本身不会播放或调用 AI。
- **本地状态**：课程绑定、目录与题目摘要、播放进度快照、最近 50 条课程日志保存在 `chrome.storage.session`；播放偏好保存在 `chrome.storage.local`。HTML 文档正文仅在页面内用于确认正文范围、布局及生成本地签名，不保存或上传正文。视频媒体地址仅计算本地签名，不保存地址正文，不读取账户 Cookie 或登录凭据。
- **AI 请求**：目录、视频与 HTML 文档内容不作为模型请求上传。仅在你主动解题，或主动开启“唯一随堂题自动预览”并开始课程且已同意 AI 数据使用后，将当前题目的题干/选项/答案区域发送给已配置的服务（手动启动整页答题时按页内顺序逐题发送）；该开关默认关闭，不自动填写或提交，可能产生费用。
- **控制**：用户开始课程后通过原播放器静音、正常播放或设置正文滚动区域的 `scrollTop` 操作；文档到底仅表示到达正文末尾，不标记平台完成。课程区可暂停/停止或清除记录；关闭浏览器会话会清除会话数据，卸载会清除本地设置。后台重启、撤回权限后不会自动恢复播放。不伪造学时、不上传学习进度、不调用平台私有进度接口或绕过验证。

### 2.4 API 访问凭证（API Key）
- **默认处理（会话级）**：你填写的 API Key 默认仅存储于浏览器的会话内存中（`chrome.storage.session`）。当浏览器关闭、扩展重载或更新时，密钥自动在内存中销毁，不写入硬盘。
- **可选持久化加密存储**：若你勾选“口令加密保存到本机”，扩展将调用 Web Cryptography API：
  - 采用 **PBKDF2-SHA256**（600,000 次哈希迭代，配以随机生成的 16 字节 Salt）派生高强度加密密钥；
  - 采用 **AES-GCM-256**（结合随机 12 字节 IV 与服务域名 Origin 校验）对 API Key 进行强对称加密后存入 `chrome.storage.local`；
  - 你的明文口令与派生密钥绝不落盘持久化。浏览器重启后必须由你手动输入口令解锁，无法解锁时密文不可逆且无法找回。

### 2.4 本地操作与任务日志
- **数据范围**：扩展运行时产生的状态变更（如“开始读取”、“等待 AI 响应”、“填写成功”等提示信息）。
- **处理方式**：最多仅在当前会话的 `chrome.storage.session` 中保留最近 60 条记录，供面板底部日志区诊断查看。关闭扩展或点击面板“清除练习记录”即可一键销毁。

## 3. 浏览器权限的使用与合规

本扩展仅声明实现功能所绝对必需的浏览器权限。详细的权限使用场景、源码实现与隐私影响评估，请查阅独立的 **[《扩展权限使用目录与合规说明》](PERMISSIONS.md)**。

简要归纳如下：
- `activeTab` / `scripting`：用于受控地在练习页提取题目文本与自动填入选项/代码；
- `storage`：用于在本地保存你的配置选项与加密凭据；
- `sidePanel`：用于提供侧边栏交互操作面板；
- `nativeMessaging`：仅在本地 CLI 模式下与本机已安装的命令行辅助工具通信；
- `webNavigation`：感知已授权练习页中 iframe 容器的刷新与换题；
- `offscreen`：在后台稳定执行异步 API 通信与流式文本解析；
- `host_permissions`：仅预置 `https://*.chaoxing.com/*`、`https://*.zhihuishu.com/*`、`https://www.icourse163.org/*`、`https://moodle.syxy.ouchn.cn/*`，用于课程只读识别及用户启动后的正常播放/练习操作；不授权整个 `edu.cn` 或 `ouchn.cn`。可在扩展管理中限制访问，撤回访问后暂停课程。
- `optional_host_permissions`：按需申请特定做题站点或自选 API 服务商域名的访问权，不默认申请全网访问权限。

## 4. 第三方服务与数据出境

本扩展本身不提供任何大模型推理能力，题目的最终解答均依赖于你所接入的第三方服务商或本地工具：

1. **大语言模型 API 服务商**：
   - 当你在扩展中配置了服务商（如 DeepSeek、阿里云通义千问、智谱清言、月之暗面 Kimi、火山引擎豆包、OpenAI 等）并开启 API 模式时，题干数据将通过HTTPS 加密传输请求直接发送至该服务商的 API 端点。
   - **第三方隐私政策**：各模型服务商拥有独立的数据留存、模型训练及出境传输政策。请在配置前查阅对应服务商的《隐私政策》与《API 服务条款》。我们不对第三方服务商对题干的处理方式承担责任。
2. **本地 CLI 模式**：
   - 若使用本地 CLI 模式，题目将通过标准输入输出传递给你本机已登录的终端工具（Codex、Claude Code、Gemini CLI 等），其鉴权及网络传输完全遵循该工具在本机的既有配置。
3. **微信支付赞助**：
   - 赞助二维码展示完全基于本地静态图片，扫码和支付过程完全在腾讯微信平台内完成。扩展不会、也无法获取你的微信账号、交易单号、支付金额等隐私数据。
4. **外部推广链接（可选）**：
   - 界面中可能包含明确标注为“推广”的第三方服务链接（如镜像站推荐），仅在你主动点击时在新标签页中打开，扩展不向该站点同步任何用户数据。

## 5. 用户的权利与数据控制权

你对自己的所有数据拥有完全的自主控制权：

- **随时查看与核对**：你可以在侧栏展开“查看识别内容”，在发送给 AI 之前随时审查提取到的题目与代码文本。
- **清除课程记录**：在网课区点击「清除课程记录」，可清除课程绑定、目录、题目摘要、播放进度快照与课程日志，不更改平台记录或课程设置。
- **一键清除会话数据**：在面板底部点击「清除练习记录」，可即时销毁本次会话保留的所有题目快照、解题结果与运行日志。
- **清除或锁定密钥**：在「设置」中你可以随时点击“清除已保存 Key”或“锁定 Key”，立即清除内存中的明文凭证或本地密文。
- **撤回知情同意**：在「设置」中可以随时“撤回数据使用同意”，撤回后扩展将拒绝向任何外部大模型发送数据，直到你重新确认。
- **管理或移除站点授权**：在浏览器的扩展管理页中，你可以随时查看并移除已授权的练习网站或 API 域名。
- **彻底卸载与注销**：在浏览器扩展页面中点击“删除/移除扩展”，浏览器将自动清除本扩展在本地存储中的全部配置与历史密文；若安装了本地 CLI 桥，运行项目自带的 `node scripts/uninstall-native.mjs` 即可彻底注销本机注册表。
